# Recursos interactivos · Bases y fundamentos del currículo de las familias de servicios

Páginas web interactivas para la asignatura «Bases, fundamentos y aplicación del currículo de las familias de servicios en la Formación Profesional» del Máster en Profesorado (MUFPS), especialidad de Familias de Servicios.

Todas siguen el mismo caso guía: el ciclo de grado medio de Técnico en Vídeo Disc-jockey y Sonido (RD 556/2012), impartido en un instituto público de Castilla-La Mancha.

La página de inicio (`index.html`) enlaza todos los recursos.

## Uso

Cada recurso es un único archivo HTML sin dependencias, salvo las fuentes de Google Fonts. Se navega con las flechas del teclado; la tecla F activa la pantalla completa.

Para publicarlo con GitHub Pages: *Settings → Pages → Deploy from a branch*, rama `main`, carpeta raíz.

## Vigencia

Normativa comprobada a octubre de 2026. Las páginas resumen la normativa con fines didácticos y no sustituyen la consulta del BOE ni del DOCM.
